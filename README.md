# Neptune View™

**Neptune View™** is a retro-inspired video-sharing platform developed as part of **Neptune Corporation™**.

It is designed around a simple idea:

> You should be able to discover videos without an algorithm deciding what you should watch.

Neptune View takes inspiration from classic 2000s-era social and video websites, emphasizing user-controlled discovery, subscriptions, search, categories, tags, favorites, and random discovery.

## Features

* Video browsing
* Video watch pages
* Video metadata
* Categories
* Tags
* Channel profiles
* Channel subscriptions
* Comments
* Likes
* Favorites
* Search
* Random Video
* Retro 2000s-inspired interface
* Client-side data storage for user interactions

## Discovery

Neptune View does not use a recommendation algorithm in v0.01.

Users can discover videos through:

* Search
* Categories
* Tags
* Channels
* Subscriptions
* Favorites
* Random Video
* Manual browsing

## Development

Clone the repository and install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build the project:

```bash
npm run build
```

## Philosophy

Neptune View is built around user choice rather than algorithmic recommendations.

The platform should help users find what they are looking for without constantly attempting to predict what they should watch next.
