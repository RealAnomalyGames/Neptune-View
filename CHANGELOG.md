# Changelog

## v0.01 — Initial Release

### Added

* Initial Neptune View™ website
* Retro 2000s-inspired interface
* Client-side page routing
* Video data model
* Video browsing
* Video watch pages
* Video metadata
* Categories
* Tags
* Channel profiles
* Channel pages
* Channel subscriptions
* Comments
* Likes
* Favorites
* Favorites page
* Search
* Random Video
* Local persistence for user interactions

### Known Limitations

* No backend
* No real user accounts
* No real video hosting
* No video uploading backend
* User data is stored locally in the browser
* Video data is currently provided by the application
* Search is performed client-side
* Random Video only selects from the currently available video dataset
* No moderation system
* No authentication system
* No server-side database

### Release Status

Neptune View™ v0.01 is an early development release establishing the foundation of the platform.
